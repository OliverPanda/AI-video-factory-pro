## 5. 建议的执行顺序

为避免并行开发互相阻塞，建议按下面顺序推进：

1. 先完成 M0，收拢基线
2. 紧接着完成 M1，先把后处理产物稳定下来
3. M2 与 M3 并行推进，但以前者消费 M1 mock 数据、后者补真实编辑 API 为边界
4. M4 统一做联调、回归、错误处理收口
5. M5 只做上线材料、文档、UAT、Tag 和 Demo
