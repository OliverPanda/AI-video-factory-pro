### 8.1 正确全量姿势（关键前提，先于一切修复）

全量入口 `scripts/run-tests.js` 为**单进程顺序 import**，且 `director.js:516 isNodeTestRuntime()` 仅认 `NODE_TEST_CONTEXT` 或 `--test` argv。缺此标记时 director 默认依赖会选**真实 provider**（generateCharacterRefSheets / runVideoGeneration…），集成测试将真实请求外部 API（实测打到 `api.apilio.ai/v1` 返回 400）。Bash 每次调用是新 shell、env 不跨调用保留，因此**每次全量必须显式注入**：

```bash
NODE_TEST_CONTEXT=1 QUEUE_EXECUTION_POLICY=test node scripts/run-tests.js
```

本 session 前两次量测（47 fail / 41 fail）均因漏注入 `NODE_TEST_CONTEXT` 失真，属测量方式错误而非回归。
